# MVBotsHub

> Платформа для управления Telegram-ботами, сценариями общения и массовыми рассылками.

**Версия документации:** 1.0 (Draft)

---

# О проекте

**MVBotsHub** — это модульная платформа для разработки, управления и эксплуатации Telegram-ботов.

Платформа позволяет создавать неограниченное количество ботов, проектировать сценарии общения с помощью визуального редактора, управлять пользователями, выполнять массовые рассылки и анализировать статистику взаимодействия.

Одно развертывание платформы обслуживает любое количество Telegram-ботов, при этом каждый бот полностью изолирован на уровне данных и бизнес-логики.

---

# Основные возможности

Платформа предоставляет следующие возможности:

- управление неограниченным количеством Telegram-ботов;
- визуальный редактор сценариев (Flow Builder);
- поддержка сложных диалогов;
- поддержка нескольких языков;
- массовые рассылки с учетом ограничений Telegram;
- управление доступом сотрудников к ботам;
- централизованная административная панель;
- сбор статистики и аналитики;
- расширяемая архитектура для интеграции с внешними сервисами.

---

# Цели проекта

При разработке MVBotsHub преследуются следующие цели:

- высокая производительность;
- простота сопровождения;
- масштабируемость;
- независимость бизнес-логики от используемых технологий;
- возможность длительной эксплуатации без архитектурных изменений.

# Основные принципы модели данных

Платформа разделяет пользователей системы и пользователей ботов.

## User

Пользователь административной панели.

Выполняет управление системой.

Авторизуется в MVBotsHub.

---

## Person

Реальный человек.

Может одновременно взаимодействовать с несколькими ботами.

---

## BotMember

Связь между Person и Bot.

Именно здесь хранится информация, относящаяся к взаимодействию человека с конкретным ботом.

---

# Управление доступом

Права сотрудников определяются двумя уровнями.

## Глобальные права

Определяют доступ к административной панели и системным функциям.

Реализуются через Laravel и Spatie Permission.

---

## Права на конкретного бота

Определяются сущностью **BotAccess**.

Каждый пользователь системы видит только тех ботов, к которым ему предоставлен доступ.
