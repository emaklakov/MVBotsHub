# Назначение

Настоящий раздел описывает предметную область (Domain) платформы MVBotsHub.

Документы данного раздела определяют бизнес-модель системы, основные сущности, их обязанности, инварианты и правила взаимодействия.

Настоящий раздел не описывает реализацию на Laravel, структуру базы данных, административную панель или пользовательский интерфейс.

---

# Что такое Domain

Domain — это бизнес-модель платформы.

Domain отвечает на вопросы:

- какие сущности существуют в системе;
- какие обязанности выполняет каждая сущность;
- какие ограничения действуют внутри системы;
- как сущности взаимодействуют между собой.

Domain не описывает:

- Laravel;
- HTTP;
- PostgreSQL;
- Redis;
- Telegram API;
- MoonShine;
- Vue;
- Eloquent.

Все перечисленное относится к реализации приложения.

# Основные принципы

## Единая терминология

Все документы используют определения из `docs/glossary.md`.

Использование разных терминов для одной и той же сущности не допускается.

---

## Независимость

Domain полностью независим от технологий реализации.

Изменение ORM, базы данных, административной панели или транспортного протокола не должно влиять на бизнес-модель.

---

## Разделение ответственности

Каждый модуль отвечает только за свою область ответственности.

Бизнес-правила не должны дублироваться.

---

## Независимые агрегаты

Каждый агрегат самостоятельно обеспечивает собственные инварианты.

Агрегаты взаимодействуют друг с другом только по идентификаторам и через публичные интерфейсы.

Создание "суперагрегатов" не допускается.

# Агрегаты

В системе используются небольшие независимые агрегаты.

```text
Bot
│
├── BotSettings
├── Localization
└── BotAccess
```

```text
Person
```

```text
BotMember
```

```text
Conversation
│
└── Message
```

```text
Flow
```

```text
FlowSession
```

```text
Broadcast
```

Bot является центральной бизнес-сущностью системы, но не является владельцем остальных агрегатов.

Все агрегаты связаны между собой через идентификаторы.

# Общие правила

Для всех модулей Domain действуют следующие требования.

- Каждый модуль имеет одну область ответственности.
- Каждый агрегат самостоятельно обеспечивает свои инварианты.
- Все агрегаты независимы друг от друга.
- Между агрегатами передаются только идентификаторы и необходимые данные.
- Domain не содержит зависимостей от Laravel и сторонних библиотек.
