# Назначение

Настоящий документ описывает физическую структуру исходного кода проекта MVBotsHub.

Документ определяет назначение основных каталогов приложения и правила их использования.

---

# Общая структура

Исходный код приложения расположен в каталоге `app`.

```text
app/
├── Application/
├── Console/
├── Domain/
├── Exceptions/
├── Forms/
├── Http/
├── Infrastructure/
├── Jobs/
├── Listeners/
├── Models/
├── MoonShine/
├── Policies/
└── Providers/
```

Каждый каталог имеет строго определённую область ответственности.

---

# Application

Каталог `Application` содержит сценарии использования системы и координирующую логику приложения.

Типичное содержимое:

- Services;
- Actions;
- DTO;
- Commands;
- Queries.

В данном слое НЕ размещается бизнес-логика предметной области.

---

# Console

Каталог `Console` содержит консольные команды Laravel.

Команды предназначены для обслуживания системы, запуска фоновых процессов и выполнения административных операций.

---

# Domain

Каталог `Domain` содержит предметную область приложения.

В данном каталоге располагаются:

- агрегаты;
- сущности;
- Value Objects;
- доменные сервисы;
- доменные события;
- интерфейсы репозиториев.

Каталог `Domain` не зависит от Laravel и сторонних библиотек.

---

# Exceptions

Каталог `Exceptions` содержит общие исключения приложения.

Исключения, относящиеся исключительно к одному модулю, рекомендуется размещать рядом с соответствующим модулем.

---

# Forms

Каталог `Forms` содержит формы, используемые административной панелью.

Формы относятся к слою Presentation.

---

# Http

Каталог `Http` содержит компоненты HTTP-интерфейса.

В состав каталога входят:

- Controllers;
- Middleware;
- Requests.

Контроллеры не содержат бизнес-логики и выполняют только обработку HTTP-запросов.

---

# Infrastructure

Каталог `Infrastructure` содержит технические реализации инфраструктурных компонентов.

Примеры:

- уведомления;
- интеграции;
- реализации репозиториев;
- внешние сервисы;
- файловые хранилища.

Infrastructure реализует интерфейсы, определённые в Domain.

---

# Jobs

Каталог `Jobs` содержит фоновые задачи Laravel.

Каждая задача должна выполнять одну законченную операцию.

При увеличении количества задач рекомендуется группировать их по предметным областям.

---

# Listeners

Каталог `Listeners` содержит обработчики событий приложения.

Обработчики должны быть максимально независимыми друг от друга.

---

# Models

Каталог `Models` содержит Eloquent-модели и связанные с ними классы.

Модели сгруппированы по предметным областям.

Пример:

```text
Models/
└── User/
    ├── User.php
    ├── Role.php
    ├── Permission.php
    ├── Session.php
    ├── UserLog.php
    ├── UserSetting.php
    └── Notification.php
```

Использование Eloquent-моделей допускается только за пределами слоя Domain.

---

# MoonShine

Каталог `MoonShine` содержит административную панель проекта.

Несмотря на физическое расположение в каталоге `app`, MoonShine относится к слою Presentation.

В данном каталоге располагаются:

- Resources;
- Pages;
- Components;
- Fields;
- Pages;
- другие элементы административного интерфейса.

---

# Policies

Каталог `Policies` содержит политики авторизации Laravel.

Политики используются для проверки прав доступа пользователей системы.

---

# Providers

Каталог `Providers` содержит сервис-провайдеры Laravel.

Регистрация компонентов приложения выполняется исключительно через сервис-провайдеры.

---

# Принципы организации каталогов

При добавлении нового кода необходимо соблюдать следующие правила.

## Один каталог — одна ответственность

Каждый каталог должен иметь чётко определённое назначение.

---

## Группировка по предметной области

При большом количестве классов рекомендуется использовать вложенные каталоги.

Например:

```text
Jobs/
├── Broadcast/
├── Bot/
└── Message/
```

---

## Минимизация верхнего уровня

Создание новых каталогов непосредственно в `app` допускается только при наличии архитектурного обоснования.

Предпочтительно размещать новый код внутри уже существующих каталогов.

---

## Независимость Domain

Каталог `Domain` не должен содержать зависимости от:

- Laravel;
- Eloquent;
- MoonShine;
- Telegraph;
- Redis;
- PostgreSQL;
- HTTP.
